Sister technologies

Workforce management

WFM forecasts volume and builds schedules. It consumes contact-center events. It does not parse Via headers. When a forecast is wrong, the SIP symptom is usually queue delay and 480 or carrier congestion, not a broken dialog ID.

Sources and go deeper

  • RFC 3261 §21 — last checked 2026-10

Quality management and recording

QM scores interactions. The standardized way an SBC forks a session to a recorder is SIPREC.

Sources and go deeper

E911 / emergency calling

Location has to ride with the call. RFC 6881 is the BCP, RFC 6442 carries location in SIP, and the FCC MLTS page states Kari’s Law and RAY BAUM’s Act obligations for multi-line systems.

Analytics

Amazon Connect can attach conversational analytics to an external voice system with a SIPREC connector. The analytics plane is not a second SIP proxy for the customer call.

CRM

Screen pop uses data the contact center already has: ANI, DNIS, case id. Those values may arrive in SIP headers or in a CTI event after the call is up. The CRM is not a SIP element.

Sources and go deeper

  • RFC 3261 — last checked 2026-10

AI agents

A voice bot still needs a session. On Amazon Connect the platform owns the managed PSTN voice channel. Bridging an outside carrier into Connect with a Chime Voice Connector is not a supported pattern unless AWS reviews it. The FreeSWITCH manual page also describes SignalWire, founded by the FreeSWITCH team, as a hosted platform with AI agents behind REST APIs and SWML.

Cross-platform bridges

CUCM

CUCM is the enterprise registrar and the SIP trunk endpoint toward CUBE or another SBC. A CUCM SIP Profile is an admin object. It is not a CUBE voice class sip-profiles list.

Open SIP core

Kamailio’s home page describes an open source SIP server that can front a PBX such as Asterisk or FreeSWITCH. rtpengine’s README describes the RTP proxy meant to sit with Kamailio. A CUCM SIP trunk toward that SIP server is still SIP. The CUCM SIP Profile and Asterisk’s pjsip.conf are different objects.

Browser socket

RFC 7118 requires the WebSocket subprotocol sip. Via uses WS or WSS. The URI transport parameter the RFC adds is transport=ws. A sips path that includes WebSocket must be a secure WebSocket.

Sources and go deeper

  • RFC 7118 — last checked 2026-10
  • RFC 6455 — last checked 2026-10

Troubleshooting

No SIP from the browser

Stop at the WebSocket handshake. A missing 101 means the SIP request was never framed. Codecs are not negotiated yet.

Sources and go deeper

  • RFC 7118 — last checked 2026-10
  • RFC 6455 — last checked 2026-10

SIP succeeds and audio does not

Read c= and m=, then ICE candidates, then DTLS-SRTP. A private address in c= is a reachability problem. Identity headers do not move RTP.

Sources and go deeper

  • RFC 3264 — last checked 2026-10
  • RFC 8445 — last checked 2026-10
  • RFC 5764 — last checked 2026-10

Caller identity

RFC 8224 defines the Identity header. RFC 8225 defines PASSporT. The STI-GA page describes SHAKEN. A placeholder token is not a verification. Not legal advice.

911 dialing and location

Public Law 115-127 is the direct-dial statute. Section 506 of RAY BAUM’S Act is the dispatchable-location proceeding. RFC 6442 is SIP location conveyance. Do not place a live 911 call for this lab. Not legal advice.
