Read an RFC header before you cite it

Number, category, and Obsoletes or Updates. The RFC Editor header beats a remembered month.

Takeaways

  • Read number, category, and Obsoletes or Updates
  • Keep 422 and 2xx ACK with the RFCs that define them
  • Leave publication months to the header

Learn in 5 minutes

  2. Keep 422 and 2xx ACK with the RFCs that define them

This lesson states no publication month. The current SDP number here is 8866.
