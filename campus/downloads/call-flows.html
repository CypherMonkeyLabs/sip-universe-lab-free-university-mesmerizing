Cheat sheet

Call flows to recognize

Alice        SBC          Bob
  |  INVITE    |            |
  |---------->|            |
  |  100       |  INVITE    |
  |<----------|---------->|
  |            |  180      |
  |  180       |<----------|
  |<----------|            |
  |            |  200 SDP  |
  |  200 SDP   |<----------|
  |<----------|            |
  |  ACK       |            |
  |---------->|            |
  • 100 Trying stops the retransmit. It is not ringing. RFC 3261
  • 200 OK to INVITE is acknowledged with ACK. A 200 to BYE is not. RFC 3261
  • 183 with SDP can be early media. 180 is alerting. RFC 3960
  • PRACK acknowledges a reliable 1xx. RFC 3262
  • 200 OK to CANCEL does not end the INVITE. Look for 487. RFC 3261 §9
  • REFER asks the transferee to send a new INVITE. RFC 3515

Messages in the campus are synthetic. Addresses use RFC 5737.
