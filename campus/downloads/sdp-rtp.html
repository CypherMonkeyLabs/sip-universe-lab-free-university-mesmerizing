SDP and RTP reminders

  • Port 0 rejects a media stream. RFC 3264
  • G.722 RTP clock rate is 8000 even though the audio is 16 kHz. RFC 3551 §4.5.2
  • telephone-event is the IETF digit mechanism in RTP. INFO is not the DTMF spec. RFC 4733 · RFC 6086
  • SRTP is RFC 3711. SDES (RFC 4568) and DTLS-SRTP (RFC 5764) are different keying paths.
TermIn one breath
SDPSession Description Protocol. The text format that describes media streams for offer/answer.
Offer/answerThe rule set that pairs one SDP offer with one SDP answer. The answer mirrors the offer’s m-line count and order.
RTPReal-time Transport Protocol. Carries media samples. It is not SIP.
SRTPSecure RTP. Encrypts and authenticates media packets.
telephone-eventRTP payload for DTMF and related tones.
