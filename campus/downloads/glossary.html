Cheat sheet

Core glossary

TermIn one breath
SIPSession Initiation Protocol. Application signaling that creates, modifies, and ends sessions.
SDPSession Description Protocol. The text format that describes media streams for offer/answer.
Offer/answerThe rule set that pairs one SDP offer with one SDP answer. The answer mirrors the offer’s m-line count and order.
RTPReal-time Transport Protocol. Carries media samples. It is not SIP.
SRTPSecure RTP. Encrypts and authenticates media packets.
DialogA peer relationship identified by Call-ID, local tag, and remote tag.
TransactionOne request and its responses, identified on a hop by the Via branch.
B2BUABack-to-back user agent. A UAS on one side glued to a UAC on the other. Taxonomy: RFC 7092.
ICEInteractive Connectivity Establishment. Tries candidate pairs until one works.
STUNSession Traversal Utilities for NAT. Binding checks and mapped addresses.
TURNTraversal Using Relays around NAT. Allocates a relayed media address.
PRACKProvisional acknowledgement. Makes selected 1xx responses reliable when 100rel is in use.
REFERAsks another UA to issue a request, typically for transfer.
telephone-eventRTP payload for DTMF and related tones.
SIPRECSIP recording protocol. A session is forked to a recording server.
PAIP-Asserted-Identity. An identity asserted inside a trusted network, not a cryptographic proof.
E911Emergency calling from multi-line systems. Location and routing rules are in RFC 6881 and FCC MLTS rules.
Direct RoutingMicrosoft Teams Phone connectivity through a certified customer SBC.
