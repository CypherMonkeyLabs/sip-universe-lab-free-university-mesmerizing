Trunk configuration checklist

Walk the call before you walk the GUI

Transport: UDP retransmits, TCP does not at the SIP layer the same way, TLS adds certificates. Pick the one the peer documents. Destination: an address, or a domain with NAPTR and SRV. Certificates: the name in the certificate has to match the name you dial, or the product’s own override. Codecs: the order in the offer is a preference, not a command. The answer chooses. DTMF: list telephone-event if you want RFC 4733. Do not assume SIP INFO means the same thing on every PBX.

Identity: some carriers want PAI, some want the From user to be an E.164 they assigned, some want both plus Privacy. Session timers: if one side sends Session-Expires and the other side ignores the refresh, the call ends on that timer. Registration: Expires is a request. The registrar’s 200 picks the actual interval.

RFC 3264 · RFC 4733 · RFC 6086 INFO · RFC 3323 Privacy

Trunk worksheet

  • Peer name and whether it is a domain or an IP.
  • Transport and port, including the return port.
  • TLS profile and the name in the certificate.
  • Outbound codec list and ptime.
  • DTMF: telephone-event, KPML, or a documented INFO mapping.
  • Calling identity headers and the number format.
  • Diversion or History-Info, if the carrier uses them.
  • Session-Expires and who sends the refresh.
  • Media: anchor, bypass, or ICE. RTP port range on the firewall.
  • Source addresses allowed to send INVITEs.
  • Emergency route and a test number.
  • Recording target, if SIPREC or a vendor fork is in scope.
